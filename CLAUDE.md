# Портфолио «Меню паузы» — правила работы

Альтернативная версия портфолио: сайт как экран паузы в игре. Что и почему решено, открытые вопросы, источники — `README.md`.

- Основной сайт — репозиторий `cybertatar/Portfolio`. В него этот эксперимент не заносим ни в каком виде (просьба владельца). Оттуда только берём контент: тексты и данные (`src/content/site.ts`), кейс PSB, картинки, спрайты (`src/content/mascots.ts`).
- Изменения — в отдельной ветке, в `main` сливаем после «ок» владельца.
- Сайт для ревью: https://cybertatar.github.io/portfolioalternative/ — `sketches/pause.html` как главная, деплоится сам при каждом пуше в `main` (`.github/workflows/deploy.yml`; окружение github-pages пускает только `main`; к странице там добавляются doctype и charset, артефакт добавляет их сам).
- Наброски (`sketches/*.html`) показываем владельцу артефактом; живой набросок «Меню паузы» — https://claude.ai/artifact/R8zRspeDcXpWTtsnV5bQkt (обновлять по тому же URL).
- Решения владельца и отклонённые варианты записываем в `README.md` («Что решено»), чтобы не предлагать отклонённое снова.
- Интерфейс без обводок: border и обводки через box-shadow не используем, поверхности различаются заливкой (просьба владельца).
- Без висячих предлогов: типограф как в основном сайте (`src/typograph.ts` там); в наброске `pause.html` — функция `typo`, работает через MutationObserver, отдельно вызывать не нужно.
- Отступы и скругления — только через токены (`--s1…--s7`, `--gap`, `--pad`, `--inset`, `--r`, `--r-in`, `--r-ctl`); правила — в README («Что решено»). После правок вёрстки запускать `node tools/audit-layout.js "$PWD/sketches/pause.html"`: должно быть «ok» на всех вкладках.
- Без интерпунктов (·) в интерфейсе и текстах сайта (просьба владельца: выдаёт сайт, сделанный нейросетью). Части подписи разделяем отступом, переносом или запятой.
